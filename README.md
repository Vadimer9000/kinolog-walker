# KinologWalker 🐕🐾

Профессиональное мобильное Android-приложение для кинолога-выгульщика («Кинолог-Выгульщик»).

Написано на **100% Native Kotlin** с использованием **Jetpack Compose**, **Material 3** и дизайна в стиле **Yandex Go × Apple iOS Liquid Glass**.

---

## 🛠 Технологический стек
* **Язык:** 100% Kotlin 2.0.21
* **UI-фреймворк:** Jetpack Compose (BOM 2024.10.01), Material 3
* **Платформа:** Android SDK 35 (Android 15), minSdk 33, targetSdk 35
* **База данных:** Room ORM 2.6.1 + KSP-кодогенерация
* **Сериализация:** kotlinx.serialization (JSON)
* **Фоновые задачи:** WorkManager (уведомления за 30 мин до выгула)
* **Карты и геопозиция:** WebView с Яндекс.Карты JS API v2.1 + нативные диплинки `yandexmaps://` + FusedLocationProviderClient
* **Сборка и CI/CD:** Gradle Kotlin DSL (8.10.2) + GitHub Actions runner (JDK 21)

---

## 📱 Функциональные возможности
1. **Клиентская база и питомцы (CRM):**
   * Карточки клиентов с адресами, домофонами, этажами и комментариями.
   * Динамический список питомцев (собаки, кошки, клички, породы).
   * Автоматическое геокодирование адресов клиентов.
   * Быстрый звонок и прямые ссылки в мессенджеры: **Telegram**, **WhatsApp**, **ВКонтакте**, **Max**.
2. **Умное расписание и цикличность:**
   * Категории выгулов (Обычный выгул, Дрессировка, Коррекция поведения, Передержка/Визит).
   * Движок регулярных выгулов по дням недели ([Пн]..[Вс]) до заданной даты.
   * Напоминания через push-уведомления и синхронизация с **Google Календарём**.
3. **Маршрутизация (Яндекс.Карты):**
   * Интерактивная карта с нумерованными метками времени и кличек питомцев.
   * Переключатель режима: *Пешком* vs *Общественный транспорт*.
   * Построение маршрута на весь день (N точек) от текущей геопозиции пользователя.
4. **Резервное копирование:**
   * Экспорт всей базы в JSON в «Избранное» Telegram в один клик.
   * Восстановление базы из любого сохранённого JSON-бэкапа.
